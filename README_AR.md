# فتح كلام — مشروع Android

يحتوي على نسخة HTML المرفوعة من المستخدم داخل `app/src/main/assets/index.html`، واللوجو الجديد داخل `app/src/main/assets/logo.png`، مع استخدامه كأيقونة للتطبيق.

يفتح المشروع في Android Studio ويمكن بناء APK منه. المشروع يضيف صلاحيات الميكروفون والكاميرا لأن التطبيق يحتوي على التسجيل الصوتي والمكالمات، ويحمّل صفحة HTML عبر WebView Asset Loader على أصل HTTPS محلي.
